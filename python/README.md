# Python Learning Curriculum - 100 Days of Code

A structured path from zero to confident Python developer.

## Curriculum Overview

### Week 1-2: Foundations
| Day | Topic | File |
|-----|-------|------|
| 1 | Variables, types, print, input | `exercises/day01_basics.py` |
| 2 | Strings & string methods | `exercises/day02_strings.py` |
| 3 | Numbers, math, type conversion | `exercises/day03_numbers.py` |
| 4 | Lists & list methods | `exercises/day04_lists.py` |
| 5 | Tuples & sets | `exercises/day05_tuples_sets.py` |
| 6 | Dictionaries | `exercises/day06_dicts.py` |
| 7 | If / elif / else | `exercises/day07_conditionals.py` |
| 8 | For loops | `exercises/day08_for_loops.py` |
| 9 | While loops | `exercises/day09_while_loops.py` |
| 10 | Functions (basics) | `exercises/day10_functions.py` |
| 11 | Functions (args, kwargs, return) | `exercises/day11_functions_advanced.py` |
| 12 | Scope & closures | `exercises/day12_scope.py` |
| 13 | List comprehensions | `exercises/day13_comprehensions.py` |
| 14 | Review mini-project: Number Guessing Game | |

### Week 3-4: Intermediate
| Day | Topic |
|-----|-------|
| 15 | File I/O (read/write files) |
| 16 | Exception handling (try/except) |
| 17 | Modules & imports |
| 18 | Classes & OOP basics |
| 19 | Inheritance & methods |
| 20 | Dunder methods (`__str__`, `__len__`, etc.) |
| 21 | Mini-project: To-Do List CLI app |

### Week 5-6: Standard Library & Tools
| Day | Topic |
|-----|-------|
| 22-23 | `os`, `sys`, `pathlib` |
| 24 | `datetime`, `random` |
| 25 | `json` — read/write JSON |
| 26 | `csv` — working with CSV files |
| 27 | `re` — regular expressions |
| 28 | Mini-project: File organizer script |

### Week 7-8: Practical Python
| Day | Topic |
|-----|-------|
| 29-30 | `requests` — HTTP & APIs |
| 31 | Working with APIs (weather, jokes, etc.) |
| 32-33 | `sqlite3` — basic database |
| 34 | Virtual environments & `pip` |
| 35 | Mini-project: CLI weather app |

### Week 9-10: Advanced Topics
| Day | Topic |
|-----|-------|
| 36 | Generators & `yield` |
| 37 | Decorators |
| 38 | Context managers (`with`) |
| 39 | `*args` / `**kwargs` deep dive |
| 40 | Functional tools: `map`, `filter`, `lambda` |
| 41-42 | `dataclasses` |
| 43-44 | Type hints & `mypy` |
| 45 | Mini-project: Data pipeline |

### Days 46-100: Projects
Build increasingly complex projects to cement your skills:
- **Days 46-55**: Text-based adventure game
- **Days 56-65**: Web scraper (BeautifulSoup)
- **Days 66-75**: REST API with Flask/FastAPI
- **Days 76-85**: Data analysis with pandas & matplotlib
- **Days 86-95**: Automation scripts (emails, files, etc.)
- **Days 96-100**: Capstone project of your choice

## How to Run Exercises

```bash
python3 exercises/day01_basics.py
```
